**Full-stack B2B e-commerce platform for sustainable packaging**, developed with React, Laravel and PostgreSQL.

The project includes:

* React Single Page Application.
* Laravel REST API.

* Role and permission management.
* Product catalogue and shopping cart.

* Administration panel.

* Deployment with Vercel and Railway.
